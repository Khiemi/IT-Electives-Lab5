# StudentSafeApp

**Name:** Kimberly Andilum Kismundo  
**Section:** BSIT - 3.4

C# Windows Forms student profile CRUD app connected to LocalDB (`SchoolDb`) using `Microsoft.Data.SqlClient` and parameterized queries to prevent SQL injection.

## Features
* Add, view/refresh, update, and delete student profiles (`StudentId`, `Name`, `Course`)
* Input validation, error handling, and parameterized SQL commands

## Setup
1. Create `SchoolDb` and the `Students` table in LocalDB.
2. Install `Microsoft.Data.SqlClient`, then build and run in Visual Studio.
